# Portfolio toolkit package

This folder contains the local mock deliverables for the one-person portfolio task.

Files:
- sitemap_sketch.png
- claude_project_mockup.png
- pressure_test_mockup.png
- toolkit_checklist.md
- claude_project_instructions.txt
- pressure_test_prompt.txt
- pressure_test_output.txt

How to use:
1. Open the sitemap sketch and keep it as your small, proof-first portfolio structure.
2. Copy the Claude custom instructions into a real Claude project in the browser.
3. Use the pressure-test prompt to improve the structure before publishing.

Note: actual browser account creation and screenshot capture require live access to Claude, ChatGPT, Gemini, and Perplexity in your browser.
