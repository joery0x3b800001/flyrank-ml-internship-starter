# Content / Signal — identity kit

## Type

**IBM Plex Sans** — Regular for body copy and SemiBold for headings, labels, and buttons. One free type family keeps the page consistent.

## Palette

| Role | Color |
|---|---|
| Main color — signal teal | `#2F746D` |
| Near-black text | `#202927` |
| Near-white background — warm paper | `#F7F7F2` |
| One accent — soft sage | `#DDE8E2` |

Use the sage for quiet supporting surfaces. Keep teal to links, the primary action, and occasional emphasis so the project evidence stays visually dominant.
